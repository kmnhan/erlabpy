## First notebook

You begin with photoelectron intensity measured as a function of emission angle and
energy. You will learn how to inspect and select the data and convert the angular
coordinates to crystal momentum. You will also learn how to extract dispersions along
high-symmetry directions in the Brillouin zone.

You should be able to read basic Python and run Jupyter notebook cells. If you need a
review, use the [Scientific Python Lectures](https://lectures.scientific-python.org) or
[Python tutorial](https://docs.python.org/3/tutorial/). For additional background, see
the [xarray tutorial](https://tutorial.xarray.dev/) and [xarray user guide](https://docs.xarray.dev/en/stable/).

## ImageTool Manager tutorial

Use the in-application tutorial to learn the GUI workflow.

### Starting ImageTool Manager

If you installed ERLabPy in a Python environment:

1. Open a terminal.
2. Activate the environment that contains ERLabPy.
3. Run:

   ```bash
   itool-manager
   ```

If you installed the standalone application:

- On Windows, open the Start menu and select {guilabel}`ImageTool Manager`.
- On macOS, open the Applications folder and double-click
  {guilabel}`ImageTool Manager`.

### Starting the tutorial

1. Wait for the ImageTool Manager window to appear.
2. Select {menuselection}`Help --> Tutorial`.
3. Wait until the welcome panel says that the tutorial data is ready.
4. Select {guilabel}`Start` and follow the instructions in the application.

The application contains the complete lesson.
