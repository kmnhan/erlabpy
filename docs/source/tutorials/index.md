# Tutorials

Tutorials are guided lessons for learning ERLabPy. Each lesson uses fixed inputs and
leads to a defined result.

The Python tutorial is the recommended learning path. The ImageTool Manager tutorial
introduces the GUI-centered workflow without mixing GUI instructions into the Python
lesson.

## ImageTool Manager tutorial

1. Start ImageTool Manager with `itool-manager`, or open the standalone application.
2. Select {menuselection}`Help --> Tutorial`.
3. Wait until the welcome panel says that the tutorial data is ready.
4. Select {guilabel}`Start` and follow the instructions in the application.

The application contains the complete lesson.
